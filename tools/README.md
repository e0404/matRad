# Tools

This folder contains a collection of helper functions that are not directly related to the source code of matRad.
Most users will not have use for those, but if you have something useful add it here.

- `collapsedConeKernels/`: scripts that generate the energy deposition kernels of the collapsed cone photon engine with EGSnrc/EDKnrc and fit the collapsed cone parameters (see the README in that folder).
- `matRad_validatePhotonCollapsedCone.m`: validation of the collapsed cone photon engine against the SVD pencil beam engine and ompMC.
